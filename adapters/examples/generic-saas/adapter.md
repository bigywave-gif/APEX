# Generic SaaS Adapter Example

## 角色

这是一个通用 SaaS 项目的 adapter 示例，用于展示 APEX 如何接入新项目。

## 需要映射的真相源

- 产品真相源：产品文档或 PRD
- 设计真相源：设计系统或设计规范
- 技术真相源：前端入口、路由入口、组件入口
- 验收真相源：页面验收、运行时验收、交互验收

## 最小接入清单

1. 产品映射
2. 设计映射
3. 代码入口映射
4. 页面家族映射
5. 验收映射

## 示例页面家族

- Workbench：首页、工作台、上传页
- Detail：详情页、诊断页、记录页
- Visualization：报表页、趋势页
- Management：权限、配置、模型、成员页

## 示例入口映射

- 路由入口：`src/router`
- 页面入口：`src/pages`
- 组件入口：`src/components`
- 样式入口：`src/styles`

## 接入后调用

```text
[APEX]
任务：重做报表页
范围：首屏 + 图表区 + 详情区
目标：结构清晰、视觉专业、结果可验收
阶段要求：先评估，再方案，再样例，再实现
约束：基于最新代码，不允许跳步
```
