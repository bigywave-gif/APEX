# Adapters

## 目的

本目录放 APEX 对不同项目的接入层。

## 规则

- Adapter 只做项目映射，不重复复制 APEX Core
- Adapter 只描述：
  - 产品真相源
  - 设计真相源
  - 代码入口
  - 页面家族
  - 验收映射
