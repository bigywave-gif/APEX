# 可访问性确认门

## 目的

把可访问性从“默认应当注意”提升为 APEX 的正式确认门子项。

## 适用范围

适用于所有会影响真实页面展示与交互的任务，尤其是：

- 前端改造
- 视觉升级
- 组件替换
- 表单整改
- 导航与筛选重构

## 检查项

### 视觉可访问性

- 文字与背景具备足够对比
- 状态不能只靠颜色表达
- 焦点态可见

### 结构可访问性

- 标题层级有序
- 可展开区有明确可感知入口
- 重要区域语义清晰

### 交互可访问性

- 键盘可到达关键控件
- 关键按钮、表单、筛选器可操作
- 弹层、折叠区、标签切换不会导致焦点丢失

## 与 Gate 的关系

- Gate 1：整改方案中必须说明是否涉及 A11y 风险
- Gate 2：视觉方向不能以牺牲可访问性为代价
- Gate 3：若关键可访问性项未通过，则不能宣称真实落地完成

## 最低通过条件

至少满足：

1. 关键文本可读
2. 关键控件可感知
3. 关键交互可通过键盘完成
4. 关键状态有非颜色补充信号

## 禁止状态

- 文字对比不足但仍判定完成
- 展开区域不可感知但仍判定完成
- 焦点不可见但仍判定完成
- 仅凭视觉观感好看就忽略可访问性缺口
