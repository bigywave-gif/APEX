# 优先级模型

## P0

- 稳定性、正确性与数据/状态完整性
- 准入命中
- 状态机步骤锁
- Gate 控制
- 真实验收
- 单一真相源
- 所有 APEX 交付的严格 1:1 视觉与功能约束

## P1

- 方案合理性与可恢复性
- 可复核的质量证据
- 代码基线核对
- 一致性核对
- 恢复协议

## P2

- 效率与受控 token 消耗
- skill 路由
- 审美增强
- 动效增强
- 子代理优化

## 执行规则

- P0 冲突时，P0 优先
- P1 不能覆盖 P0
- P2 只能在 P0 / P1 满足后启用
- 不得以更快完成、减少 token 或减少步骤为由削弱 P0 / P1 的准入、Gate、证据、恢复或 1:1 约束。
- 效率优化必须可解释、可回退且有明确边界；优先复用已验证的摘要、基线、契约与 Checkpoint，不得靠省略必要上下文或验收来节省 token。
- 当前范围不实现监控、指标采集、告警或监控控制台；该限制不影响既有运行审计、Gate 证据、恢复和发布审计。
- 若通用系统层与项目投影层出现冲突，优先以 `apex/` 的通用真相源为准，再修正项目投影层
