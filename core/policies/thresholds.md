# 阈值策略

## 单步输出

- 默认保持短输出
- 超过当前任务必要信息时，优先摘要而不是继续扩写
- 单步结论优先控制在“结论 + 理由 + 下一步”范围
- 当单步已能支撑下一步决策时，不再继续补充背景
- `Lite`：默认控制在 8-12 行以内
- `Standard`：默认控制在 12-20 行以内
- `Full`：用户输出按Gate摘要，内部可连续推进已授权且不需用户决策的阶段
- `Lite`：优先不超过 200 中文词
- `Standard`：优先不超过 400 中文词
- `Full`：单轮优先不超过 600 中文词

## 上下文加载

- 单步优先只读当前相关文件
- 未进入相关步骤前，不批量加载整站页面
- 基线核对阶段优先只读入口文件与当前目标页相关文件
- 除 `Full` 模式外，不一次性读取整站所有页面实现
- `Lite`：优先 1-3 个相关文件
- `Standard`：优先 3-8 个相关文件
- `Full`：单轮优先 8-15 个相关文件，超出先摘要再扩展
- 单轮如果超过默认文件数，必须先输出“已读范围摘要”

## 子代理并行

- 默认不并行
- 只有任务天然可隔离时才允许开启少量并行
- 单次并行子代理建议不超过 2-3 个
- 子代理只允许处理窄任务，不接收整套全局上下文
- `Lite`：默认 0 个
- `Standard`：默认 0-2 个
- `Full`：默认 1-3 个，但必须由主控统一裁决
- 单个子代理回传优先不超过 150 中文词

## 恢复模式

- 一旦发生中断，下一轮必须先走恢复头信息
- 恢复后先确认当前步骤和 Gate，再继续正式推进
- `Full` 模式下，超过 2 轮连续推进后，优先主动摘要一次当前状态
- `Full` 模式下，超过 3 个 Gate 前置步骤后，建议显式输出一次阶段小结

## 模式级别建议

### Lite

- 优先单线程串行
- 优先只读当前模块相关文件
- 输出保持极短

### Standard

- 允许少量并行分析
- 可读取当前页与共享组件
- 先摘要再展开

### Full

- 必须分阶段推进
- 必须使用摘要与断点恢复
- 按Checkpoint和Context Index控制上下文，不强制人为拆成多轮

## 量化使用原则

- 数值不是绝对上限，而是默认控制线
- 一旦超过默认控制线，优先摘要、拆步或切换到下一轮
- 只有在用户明确要求深挖时，才允许临时突破默认控制线
