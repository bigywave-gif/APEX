# APEX 失败与局部回退

- 轨道不确定：基于现有代码和兼容性事实判断；仍不确定时只询问会改变结果的最小问题。
- 基线与真实展示冲突：停在Existing一致性阶段，先消除漂移。
- 效果图与产品事实冲突：回到Visual修订，不把偏差留给Implement。
- Stitch确认后变化：按变化类型撤销受影响Screen或页面族Gate 2。
- Site Contract变化：重新计算依赖页面和Override，撤销受影响范围。
- 功能删除或权限变化无授权：Gate 2失败。
- 素材或依赖不可解析：继续评估候选或建立新来源准入，禁止静默替换。
- Gate 2机器校验失败：实现Worker不得启动。
- Proof失败：只回退对应实现或Bundle阶段，不无条件重跑入口。
- Gate 3失败：保持未完成态，修复明确缺口并重新验证。
