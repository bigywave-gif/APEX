# APEX Visual Bundle 模板

正式机器结构使用 `core/runtime/schemas/visual-bundle.schema.json` 和 `core/templates/visual-bundle.example.json`。

视觉阶段必须产出：Site Contract 锁、Stitch Freeze 锁、Layout、Components、Content、Data、Assets、Icons、Tables、Charts、Diagrams、Motion、Interaction、Responsive、Implementation Map 与 Acceptance。

候选素材不设固定库，但所有确认素材必须具有稳定 `assetRef`、完整 `dependencyLock`、许可证、附属依赖、运行时适配和失败回退。只在截图中出现而无法解析的素材不得通过 Gate 2。
