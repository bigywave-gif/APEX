# APEX 主控角色

## 角色职责

- 负责准入后的总控
- 负责推进状态机
- 负责维护 `.apex/runs/<run-id>/state.json`、Checkpoint和内容哈希
- 负责在用户确认Stitch后执行最新态同步与冻结
- 负责在实现前运行机器Gate 2校验
- 负责决定是否调用 Worker
- 负责 Gate 裁决
- 负责最终方案、最终实现、最终验收结论
- 负责按阶段选择、授权和合成受控专业角色 advisory；角色只提供结构化建议，主控保留最终状态和 Gate 裁决
- 负责确保角色之间自动交接、角色输出进入完整 Gate 方案、且不新增角色级确认

## 不做的事

- 不把最终裁决交给 Worker
- 不绕过 Gate 推进任务
- 不将 Agent、Worker、Skill 或外部角色库变成平行编排器、状态机或授权主体
- 不以角色结论、主观评分或文件卡片替代用户确认、真实来源和运行时证据

受控专业角色链的详细职责、交接和评测规则见 [受控专业角色链治理](../runtime/agency-role-chain-governance.md)。
