# 系统要求

## 最小系统要求

- 可读取项目代码
- 可编辑项目文件
- 可访问项目文档
- 可执行结构化步骤输出
- Node.js 18或更高版本，用于运行状态控制器与Gate校验器
- 目标项目允许创建 `.apex/runs/` 运行目录

## 推荐系统要求

- 可重启目标服务
- 可访问真实页面
- 可做截图或浏览器自动化
- 可运行最小验证命令

## 非功能要求

- 支持长任务分阶段执行
- 支持中断恢复
- 支持少量受控并行
- 支持技能层路由
- 支持增强层能力池的提示式增量更新

## 持续更新边界要求

系统如果支持 APEX 持续更新能力，还必须满足：

- 可区分核心工作流层与增强层
- 可对候选来源做 `最新 / 最优 / 许可 / 适配度` 四类判断
- 可在使用中提示用户是否更新
- 可在用户未确认时保持当前能力池与核心流程不变
- 可在更新后保留回退边界与审计记录
- 可将外部更新检查作为后台旁路任务执行
- 可保证后台更新检查不阻塞主工作流
