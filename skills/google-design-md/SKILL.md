# Google DESIGN.md Contract Bridge

Use the official `google-labs-code/design.md` contract as APEX's machine-readable design baseline.

1. Existing projects: read the real `DESIGN.md`, styles, tokens and representative components; preserve the frozen Existing baseline unless the confirmed change scope authorizes a delta.
2. Greenfield projects: define colors, typography, spacing, elevation, shapes and component tokens before the visual plan.
3. Record which rules constrain layout, components, states and motion.
4. Validate the resulting `DESIGN.md` with the official `@google/design.md` CLI when available.

This Skill defines the design contract. It does not replace APEX Router, Gate authorization, real project code, runtime evidence, or implementation.
