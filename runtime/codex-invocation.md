# Codex Invocation Compatibility Entry

This compatibility entry preserves discovery for older APEX Bridge versions.

The single normative invocation contract is [`../core/runtime/invocation-spec.md`](../core/runtime/invocation-spec.md). The host must read that file completely before creating, resuming, restarting or mutating an APEX run. This file does not define a parallel workflow and must not be used as a shortened substitute.
